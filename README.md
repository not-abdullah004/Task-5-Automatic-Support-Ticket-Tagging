# Task-5-Automatic-Support-Ticket-Tagging
📌 Overview

This task focuses on automatically classifying support tickets into relevant categories using machine learning.

📂 Files

Task5_Auto_Tagging.ipynb – Notebook for training and evaluating the tagging model

support_tickets.csv – Raw support ticket data

tagged_support_tickets.csv – Dataset with predicted tags

🧠 Objective

To build a system that:

Learns from historical support tickets

Automatically assigns tags (e.g., Billing, Technical, Account)

Improves customer support efficiency

⚙️ Technologies Used

Python

Pandas

Scikit-learn

Text vectorization (TF-IDF / similar)

▶️ How to Run

Open Task5_Auto_Tagging.ipynb

Ensure support_tickets.csv is available

Run all cells to train and evaluate the model

Tagged output will be saved as tagged_support_tickets.csv

📊 Output

Predicted tags for each support ticket

Evaluation metrics for classification performance
